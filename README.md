# Propr

Lightweight native macOS menu bar app for instant AI text refinement anywhere.  
Opens in the menu bar. Floating bar appears over any app when you focus a text field. One-click apply with smooth typing animation.

Different style from Cue, same core job.

## For people coming from Flutter / React Native / Next.js

This is a **native Swift + SwiftUI macOS app**. It runs as a real macOS application (not a web view). You build it with Xcode.

### Prerequisites (one-time)

1. macOS 14+ (Sonoma or newer)
2. Xcode 16+ installed from the Mac App Store (you already have it)
3. Nothing else. No Node, no Flutter, no Cocoapods.

### Build & Run (exact steps)

1. Open Terminal and go to this folder:
   ```bash
   cd /Users/tharusha/Projects/oss/popr
   ```

2. Generate the Xcode project (one command):
   ```bash
   xcodegen generate
   ```
   You should see "Generated project at Propr.xcodeproj".

3. Open the project in Xcode:
   ```bash
   open Propr.xcodeproj
   ```

4. In Xcode:
   - Wait for it to finish indexing (top progress bar disappears).
   - Press **Cmd + R** (or click the ▶️ Play button top left).
   - The app will build and launch.

5. First time behavior:
   - A small icon appears in your menu bar (top right, near battery/clock).
   - No main window opens — this is correct (it's a menu bar only app).
   - Click the icon → you should see a menu with "Settings..." and "Quit Propr".
   - On first run macOS will ask for Accessibility permission (this is required so Propr can see what text field you're typing in). Click **Open System Settings** and enable it for Propr.

6. Quit the app:
   - Click the menu bar icon → "Quit Propr", **or**
   - In Xcode press **Cmd + .** (stop), **or**
   - In Xcode: Product → Stop

### Clean build (if something feels broken)

In Xcode: Product → Clean Build Folder (Shift + Cmd + K), then Cmd + R again.
